# 대대일모 모바일 UI 프로토타입

배재대학교와 계명대학교의 공강 추천·시간표·공간 리뷰를 체험하는 모바일 화면입니다. 모든 화면은 모바일 폭(최대 430px), 하단 내비게이션, 전체 화면 상세와 리뷰로 구성됩니다. 웹으로 실행하는 프로토타입이며 Android APK나 iOS 앱 빌드는 아닙니다.

## 실행

- npm install
- npm run dev
- npm run build
- node --experimental-strip-types scripts/test-notices.mjs

## 구현 기능

- 두 학교 선택과 명시적 데모 입장
- 사용자가 직접 입력하는 주간 시간표, 수업 추가·삭제와 충돌 검사
- 수업 사이 빈 시간과 이동 여유 10분에 따른 예시 활동 추천
- 예시 활동 검색·분류·저장, 행사 시간과 마감일 구분
- 학교별 예시 공간 리뷰, 별점, 작성·수정·삭제와 차단 체험
- 마감 알림 설정 체험
- 실제 공개 공지 조회와 원문 링크: 배재대 일반공지와 계명대 학사공지

## 실제 공지 연결

GET /api/notices?school=pcu 또는 school=kmu

서버가 미리 지정된 학교 HTTPS 주소에서만 공지 제목·원문 링크를 읽습니다. 임의 URL을 받을 수 없으며, 외부 도메인 링크는 파싱에서 제외합니다. 실시간 조회 성공 시 5분간 캐시합니다. 실패 시 data/school-notices.json의 실제 수집 자료와 확인 시각, 연결 지연 안내를 함께 돌려줍니다. 예시 활동을 실제 공지로 대체하지 않습니다.

확인 결과: 로컬 API에서 배재대는 live 12건, 계명대는 TLS 연결 문제로 snapshot 15건을 반환했습니다. 계명대 공개 페이지 자체는 시스템 인증서를 사용하는 curl로 읽었고, 수집 결과를 스냅샷으로 기록했습니다. 인증서 검증을 끄지 않았습니다. 게시 시점 이후의 실시간 연결 상태는 달라질 수 있습니다.

## 학교 계정 인증 조사와 미완료 항목

사용자가 정한 이용 조건은 재학 상태와 관계없이 '학교 사이트 로그인 성공'입니다. 시간표 자동 가져오기는 요구사항에서 제외되어 구현하지 않습니다.

- 배재대: https://course.pcu.ac.kr/login.php 에서 SSO 로그인과 외부인 로그인 분리를 확인했습니다. 열람한 SSO 링크에는 다른 대학 도메인이 포함되어 있어 계정 검증 용도로 연결하지 않았습니다. 공식 포털 인증 흐름의 확인이 더 필요합니다.
- 계명대: https://sso.kmu.ac.kr/kmusso/ext/edward/login_form.do 에서 login_process.do POST 양식과 공개 로그인 스크립트를 확인했습니다. 실제 계정의 로그인 성공 응답, 오류 응답, 쿠키 수명과 외부 서비스용 검증 수단은 확인하지 않았습니다.
- 두 대학 모두 외부 서비스용 인증 연동 문서/승인은 제공되지 않았습니다. 문서가 없다는 이유만으로 기술적으로 불가능하다고 단정하지 않습니다. 공식 연동 제공 여부 또는 승인된 계정 테스트 환경에서 성공/실패·세션 동작을 검증해야 합니다.

실제 학교 인증은 미연결입니다. 로그인 버튼은 비활성 상태이고 비밀번호를 수집하지 않습니다. POST /api/school-auth는 항상 503과 authenticated:false를 반환하며 인증 세션을 발급하지 않습니다. 데모 입장, 학교 페이지 방문, 클라이언트 성공 플래그를 실제 학교 인증으로 인정하지 않습니다. 프로덕션 학교 계정 전용 커뮤니티의 접근 제어는 아직 구현되지 않았습니다.

## 데모 데이터와 검증 범위

개인 시간표·저장 목록·리뷰 변경은 메모리에만 있고 새로고침하면 초기화됩니다. 실제 신청, 푸시 발송, 운영자 신고 처리는 연결하지 않았습니다.

프로덕션 빌드, TypeScript 검사, 작성한 app 및 공지 파서의 lint, 공지 파서의 링크 검증 테스트, 로컬 API 응답을 확인합니다. 기본 템플릿의 사용하지 않는 UI 컴포넌트에는 기존 lint 오류가 있어 해당 공급 코드는 수정하지 않았습니다. 브라우저 조작 테스트는 요청되지 않아 실행하지 않습니다. 선택적 WebMCP 도구는 지원 브라우저에서만 등록하며 현재 환경에서 실제 등록·실행은 검증하지 않았습니다.
